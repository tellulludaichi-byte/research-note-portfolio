# Research Note

**項目を埋めるだけで卒論の骨組みができていく、卒業研究専用の管理アプリ**

Notionなどの汎用ツールと違い、卒論の流れに最初から沿って設計されています。何を書けばいいかが最初からわかる状態を目指しています。

## 主な機能

- **研究題目の管理** — 変更履歴・キーワードタグを自動記録
- **先行研究の管理** — 論文カード形式・SIST/APA形式の引用プレビュー・DOI自動入力（CrossRef API）
- **実験・調査の記録** — 実験カードが連鎖し「次の仮説」を次カードへ引き継ぎ
- **参考文献の自動生成** — 先行研究から自動一覧化・あいうえお/ABC順ソート
- **数式入力** — LaTeXプレビュー対応（`$...$` 検出）
- **テキスト出力** — 全内容をtxtファイルに出力（AI連携用途に対応）
- **バックアップ・復元** — JSONファイルへのエクスポート・インポート
- **日英併記UI** — 外国人指導教員との共有にも対応

## インストール方法

> **現在βテスト中のため、配布は個別にご連絡ください。**

### Windows

1. `.exe` ファイルを実行
2. 「WindowsによってPCが保護されました」と表示された場合 → **「詳細情報」→「実行」**

### Mac

1. `.dmg` ファイルを開いてアプリをApplicationsにドラッグ
2. 初回起動時に警告が出た場合：
   - macOS Ventura / Sonoma：**右クリック→「開く」→「開く」**
   - macOS Sequoia以降：一度ダブルクリック後、**システム設定→プライバシーとセキュリティ→「このまま開く」**

> コード署名なしのためセキュリティ警告が表示されますが、一度許可すれば次回から通常通り起動できます。
